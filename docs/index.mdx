## MCP shape

**One server, many adapters** ([ADR 0009](/decisions/0009_one_mcp_server_with_adapters)):
configure a single Universal Automation MCP entry; add platforms by adapter
packages on the registry, not by spawning separate per-OS MCP servers.

## Packages (monorepo)

- `universal_automation_*` — contracts, semantics, conformance, toolkit (CLI + one MCP server)
- `universal_driver_*` / `universal_browser_*` — platform drivers
- `universal_screencast`, `universal_capture_*`, `universal_webrtc*`
- [`universal_lexicon`](https://github.com/xsoulspace/dart_flutter_packages/tree/main/pkgs/universal_lexicon) — not vendored in this workspace
- [`universal_tooling_runtime`](https://pub.dev/packages/universal_tooling_runtime) — bounded process runs and admission policy (macOS/Linux; Windows deferred)

Sibling Flutter app harness: [mcp_flutter](https://github.com/Arenukvern/mcp_flutter).
