## Packages (monorepo)

- `universal_automation_*` — contracts, semantics, conformance, toolkit (CLI + MCP)
- `universal_driver_*` / `universal_browser_*` — platform drivers
- `universal_screencast`, `universal_capture_*`, `universal_webrtc*`
- [`universal_lexicon`](https://github.com/xsoulspace/dart_flutter_packages/tree/main/pkgs/universal_lexicon) — in [`dart_flutter_packages`](https://github.com/xsoulspace/dart_flutter_packages) (not vendored here)
- `universal_tooling_runtime` — bounded process runs and admission policy (macOS/Linux; Windows deferred)

Sibling Flutter app harness: [mcp_flutter](https://github.com/Arenukvern/mcp_flutter).
