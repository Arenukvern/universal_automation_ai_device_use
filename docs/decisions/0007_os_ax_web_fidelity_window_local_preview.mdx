# ADR 0007 — OS-AX web fidelity, window-local pointer, preview stream

**Status:** Accepted (2026-10-26)

## Summary

macOS `osAccessibility` sessions can observe browser page content via
web-first AX walks, act on background forms with window-local semantic
`clickAt`, and poll window PNG previews — without attaching a CDP endpoint.

See the family ADR for the full decision, non-claims, and evidence paths.
