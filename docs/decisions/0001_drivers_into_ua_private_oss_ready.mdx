# ADR 0001 — Drivers into UA workspace (private repo, OSS-ready publish)

**Status:** Accepted (2026-10-14)  
**Decision:** Approach A — one monorepo for automation contracts + drivers;
GitHub stays **private**; packages prepared and published to pub.dev in
dependency order when credentials allow.

## Move set (from DFP)

- `universal_driver_{macos,linux,windows}`
- `universal_browser_{cdp,webdriver}`
- `universal_screencast`
- `universal_capture_{macos,flutter}`
- `universal_webrtc`, `universal_webrtc_raw`

## Stay in DFP

- `universal_storage_*`, `universal_lexicon`
- `xsoulspace_permission_core`, `xsoulspace_lints` (path/git overrides until
  consumers resolve hosted)

## Non-goals

- Flipping GitHub visibility to public
- Renaming the repository
- Moving storage / lexicon families

## Publish order

1. `universal_automation_interface`
2. `universal_automation_semantics`, `universal_automation_conformance`
3. `universal_webrtc_raw` (no UA deps)
4. OS drivers + browser drivers + screencast (need interface/conformance)
5. capture_* + `universal_webrtc`
6. `universal_automation_toolkit`
