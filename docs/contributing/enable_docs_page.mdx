# Enable and preview docs.page

User-facing docs publish with [docs.page](https://docs.page) from root
[`docs.json`](https://github.com/Arenukvern/universal_automation_ai_device_use/blob/main/docs.json)
and the [`docs/`](https://github.com/Arenukvern/universal_automation_ai_device_use/tree/main/docs) tree.

**Live site (public repo):** [https://docs.page/arenukvern/universal_automation_ai_device_use](https://docs.page/arenukvern/universal_automation_ai_device_use)

## Prerequisites

- Public GitHub repository `Arenukvern/universal_automation_ai_device_use`
- Default branch `main` with `docs.json` at repo root
- Pages under `docs/` referenced from `docs.json` sidebar `href` values (no file extension in `href`)

## Local preview

1. Open [https://docs.page/preview](https://docs.page/preview).
2. Select the **repository root** (folder containing `docs.json`).
3. Edit `docs/**` and save to refresh.

Branch previews: `https://docs.page/arenukvern/universal_automation_ai_device_use~<branch>`.

## CI check

```bash
npx --yes @docs.page/cli check
```

Runs on pull requests via `.github/workflows/docs.yml`.

## Publishing

1. Edit docs under `docs/`.
2. Update `docs.json` sidebar when adding routes.
3. Run `npx --yes @docs.page/cli check`.
4. Merge to `main` — docs.page rebuilds automatically.
