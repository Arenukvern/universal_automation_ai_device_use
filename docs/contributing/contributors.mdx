# Contributors

This project is community-built.

The canonical roster is managed with
[all-contributors](https://allcontributors.org/) in
[`.all-contributorsrc`](https://github.com/Arenukvern/universal_automation_ai_device_use/blob/main/.all-contributorsrc).
The rendered table lives in the
[README](https://github.com/Arenukvern/universal_automation_ai_device_use#contributors).

## Adding a contributor

```bash
npx all-contributors-cli add <github-login> code,doc
npx all-contributors-cli generate
```

Commit `.all-contributorsrc` and `README.md` together. Use accurate types:
`code`, `doc`, `bug`, `userTesting`, `infra`, `security`, `research`,
`maintenance`, `tutorial`.
